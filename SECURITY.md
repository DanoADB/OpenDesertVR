# Security reporting

Use GitHub private vulnerability reporting when enabled, or contact the
repository owner privately through GitHub. Do not publish secrets, personal
identifiers, game payloads or exploit details before coordination.
Only the current M0 branch is maintained; no production security claims exist.
Dependencies are pinned; updates require source/license review and testing.
The host runs locally, loads the user's installed OpenXR runtime, does not
access the game, and performs no network communication or telemetry.
