# Contributing

Build and run CTest in both Windows presets before submitting changes.
Keep XR/graphics/core independent of game adapters. Include a reproducer,
evidence grade (headless, hardware, game), runtime and build version with bugs.
Do not include account names, serial numbers, full paths, game bytes or dumps.

New original contributions are submitted under LICENSE-MIT with permission
from their authors. Preserve existing CC0 and third-party notices.
M0 accepts no game hooks, offsets, injection, assets, proprietary mod code,
telemetry, DRM bypass or anti-cheat avoidance. Hardware evidence must be actual
observations. Use Unsupported/Unverified for unknown compatibility.
