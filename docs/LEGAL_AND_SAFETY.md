# Project boundaries

Use legally obtained software and respect its terms and protections.
M0 runs as an independent application. It does not locate or modify the game,
inject DLLs, hook rendering, access game memory, distribute proprietary bytes,
bypass DRM or anti-cheat, or enable stealth persistence.
No paid/proprietary injector dependency or telemetry is included.

Use the synthetic headset scene in a clear area, seated if preferred.
It contains stationary near/mid/far objects at eye height in LOCAL coordinates.
Stop if uncomfortable. Timing and comfort are hardware-dependent and unverified.
G1 must document permissions, protections and stop conditions before any
integration technique is proposed. Refer licensing questions to the owner;
do not assume a public source repository permits copying.
