# Evidence discipline

Keep headless test, software GPU, actual headset and actual game evidence
separate. PASS means the named check actually ran and passed; FAIL means a
named requirement failed; NOT_RUN means no observation. A PASS for submission
is not a PASS for perceived stereo, comfort or game support.

Reports generated by odv-cli and odv-testhost include schema_version 1.
No persistent machine identifiers or external runtime messages are exported.
Before sharing additional screenshots/logs, remove private paths and identifiers.
Do not commit raw game dumps or account details.

For manual headset records, include build commit, runtime family/version,
non-unique GPU/HMD models, duration, pose/depth observations, frame statistics,
shutdown sequence and any errors. Device serials are unnecessary.
